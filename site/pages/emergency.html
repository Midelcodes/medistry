Emergency Access

Start an Emergency Break-Glass

For an unconscious patient with a locked phone. Enter the code printed on their wallet card or wristband, or scan the QR code or NFC tag, which opens the same gate.

Enter the emergency code

Codes look like K7QM-4T9X-2HDP-8W2. Dashes, spaces and lowercase are fine.

Anyone can reach the gate, but it shows no personal data until a verified clinician signs in. Every attempt is logged.

What happens next

  1. The gate checks the code and asks the clinician to sign in with an authenticator code.
  2. The clinician states a clinical reason. “Other” needs written justification.
  3. A read-only triage summary opens for 60 minutes and the patient is alerted.
  4. A second clinician can co-sign to unlock the full history.
